# 🏙️ AI Smart Civic Services

> A full-stack AI-powered civic complaint management system built for the hackathon.  
> Citizens report local problems → AI classifies, prioritizes & summarizes → Government resolves faster.

## 🌟 Features

| Feature | Description |
|---------|-------------|
| 🤖 **AI Classification** | Gemini AI auto-detects category (Water, Roads, Waste, Electricity, etc.) |
| 🎯 **Priority Prediction** | AI assigns Low / Medium / High / Critical based on severity |
| 📝 **Auto-Summary** | One-sentence briefing for the repair team, generated by AI |
| 🔄 **Keyword Fallback** | If Gemini API is unavailable, a rule-based classifier takes over |
| 🏢 **Auto Department Routing** | Complaint auto-assigned to the right government department |
| 📊 **Statistics Dashboard** | Mean/median/mode resolution times, trend charts, top locations |
| 🔍 **Search & Filter** | Filter by category, priority, status; full-text search |
| 📱 **Responsive UI** | Works on mobile and desktop |

## 🤖 AI Implementation

### What the AI Does
1. **Classifies** the complaint into 8 civic categories
2. **Predicts priority** (Low / Medium / High / Critical)
3. **Summarizes** in one sentence for the repair team

### Prompt Strategy (Gemini)
```
You are an expert AI assistant for a government civic complaint system.
Analyze this complaint and respond ONLY with valid JSON:
{ category, priority, summary, confidence, reasoning }
```

### Fallback Classifier
When the Gemini API is unavailable, a keyword rule-based classifier runs instead.
It matches complaint text against known keyword sets and adjusts priority based
on urgency words ("urgent", "emergency", "danger", etc.).

### Known Limitations
- AI may misclassify ambiguous complaints (e.g. "dirty water" → Water or Sanitation?)
- Confidence scores from Gemini are self-reported and may be overestimated
- Fallback classifier has lower accuracy (~60–70%) vs Gemini (~90%+)
- No image analysis in current version

## 📊 Statistics (Batch 4 Focus)

The `StatisticsEngine` class computes (pure Python, no pandas):
- **Mean** resolution time
- **Median** resolution time  
- **Sample Variance** and **Standard Deviation**
- **Mode bucket** (most common resolution time range)
- **Daily trend** counts (30-day window)
- **Top reported locations** by frequency
- **AI confidence** descriptive stats

## 🛠️ Setup & Run Locally

### Prerequisites
- Python 3.11+
- A Google Gemini API key (free at https://aistudio.google.com/)

### Installation

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/ai-civic-services
cd ai-civic-services

# 2. Install backend dependencies
cd backend
pip install -r requirements.txt

# 3. Set your Gemini API key
cp .env.example .env
# Edit .env and add: GEMINI_API_KEY=your_key_here

# 4. Load the .env and start the server
# On Windows PowerShell:
$env:GEMINI_API_KEY="your_key_here"
uvicorn main:app --reload

# 5. Open in browser
# Citizen portal: http://localhost:8000/
# Admin dashboard: http://localhost:8000/admin
# API docs:        http://localhost:8000/docs
```

## 🌐 API Endpoints

| Method | Route | Description |
|--------|-------|-------------|
| `POST` | `/api/complaints` | Submit a complaint (triggers AI analysis) |
| `GET`  | `/api/complaints` | List all complaints (filter by category/priority/status/search) |
| `GET`  | `/api/complaints/{id}` | Get single complaint |
| `PATCH`| `/api/complaints/{id}` | Update status / department / notes |
| `GET`  | `/api/statistics` | Full dashboard statistics |
| `GET`  | `/api/meta` | Enum values for frontend dropdowns |
| `GET`  | `/api/health` | Health check + AI status |

## 🚀 Deployment (Render)

1. Push code to GitHub
2. Create a new **Web Service** on [Render](https://render.com)
3. Connect your GitHub repo
4. Set environment variable: `GEMINI_API_KEY = your_key`
5. Build command: `pip install -r requirements.txt`
6. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
7. Root directory: `backend`
